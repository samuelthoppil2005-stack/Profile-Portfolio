# Samuel Paul Thoppil — Portfolio

A responsive personal portfolio built with plain HTML, CSS, and JavaScript.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in your browser, or use the VS Code Live Server extension.
3. Update the project links and add your profile photo before publishing.

## Personalise before publishing
- Add your profile photo to this folder and name it `profile.png` (square image recommended). The site will fall back to initials until the photo is present.
- Add your LinkedIn URL to the contact links.
- Add the correct GitHub repository/demo URL to each project card.
- Review the public contact details and remove anything you do not want to publish.
- `resume.pdf` is included and linked from the hero and contact sections; replace it with your latest resume when needed.
- LinkedIn and project demo links were not provided, so they have not been invented or added.

## Deploy
You can deploy the folder using GitHub Pages, Netlify, or Vercel. For GitHub Pages, upload these files to the root of your intended Pages repository.

## Included
- `index.html` — page content
- `style.css` — styling, responsive layout, animations
- `script.js` — mobile navigation, scroll progress, reveal animations

The site uses Google Fonts and therefore needs an internet connection to load those fonts. It still works without them using system fallback fonts.
